### 连续模型转换为离散模型思路
#### 对应的实现代码文件为TopoTools.cpp
- OCC 读取模型结构有 2种（或更多）方式
  - 一种是整个模型是一个TopoCompound（混合体），然后只有一个TopoSolid
    - 不太符合导师对模型结构的要求
  - 一种是以树形结构读取，这种结构可以看CADFix、FreeCAD、Mayo（后两者都基于OCC实现，可以查看结构）。
    - 目前采用此结构，但此结构也不能满足导师的要求，因为该结构中并不是所有TopoShell都在TopoSolid中。
    - 因此我在导师推荐下，思路是 没有在TopoSolid结构下的Shell，将这些TopoShell根据**TDFLabel**分类，属于一个TDFLabel就创建一个TopoSolid
    - 所以你会发现最后**体**的数量大于CAD软件中**体**的数量
- 调用顺序
  - `importSTEP()`或`importIGES()`
  - `getBodies()`
    - `traverseLabels()`依据根标签，获取树状结构下所有TopoSolid，所有TopoShell
    - `convertToBody()`重载一 将原生TopoSolid转换为Body
    - `convertToBody()`重载二 将分类后的TopoShell，按组转换为Body
- 目前存在问题：

  - `convertToNurbsSurface()`在处理圆柱体时会有问题，可能是精度问题超过了2π，然后报错
  - 目前离散采用的是一个面离散一次，不太清楚将整个模型离散，和单独将每一个面进行离散，会有哪些问题。并且也没搞清楚这个线性偏差是什么，用的时候越小，面离散的越细

## 连续模型短边合并
#### 对应的实现代码文件为MergeShortEdge.cpp
#### 背景：因为各种原因，读入stp代表的cad文件后，模型可能存在一些细小的短边，而有些短边可能会影响下游的网格生成质量。所以这个短边合并功能就是为了提升网格生成时的模型输入质量，对短边进行合并。
#### 能够进行合并的候选对首先要满足下面三点要求：
- 其中一条边长度小于长度阈值
- 两边之间夹角大于角度阈值，在当前的设计是手动定义的
- 两边之间的连接点没有第三条边连接，也就是连接点的度数是2
#### 满足以上要求的候选对才能进行合并，且合并过程应该越轻量越好，比如能通过修改拓扑的方式合并就应只修改拓扑而不动底层几何。

### 添加对不适合合并的edge的检测
#### 对应函数isHighRiskEdge()
#### 四种不适合合并的edge
- 退化边：3D 空间中长度为零（缩为一个点），但在 参数空间中具有非零长度 的边。例如球体展成矩形，矩形的顶边和底边分别对应北极和南极。
- 缝合边：因为它在一个 face 上可能有两条 pcurve，不适合像普通边一样修改。
- 闭合边：因为它首尾是同一个顶点。例如一个Geom_Circle类型的edge。
- 没有稳定 3D curve / pcurve 表示的边：有些边可能没有基曲线的表示。
